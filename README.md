# Age Fitter Tool

This program adjusts inputs for a mean and SD in the model to work in a truncated normal distribution.

## Usage

Enter the desired mean and SD of initial age, along with the upper and lower age bounds (in months). You have the option to specify a "weight for the mean" that indicates how much to prioritise the mean vs the SD in the optimisation algorithm.

[Link to run the tool](https://virginia-apps.shinyapps.io/AgeFitter/)
